# خارطة الطريق — نظام تك زون للإلكترونيات

> ⚠️ **القاعدة المعمارية والتوثيقية الإلزامية لأي نموذج ذكاء اصطناعي أو مطور (Mandatory Modular Plug-and-Play & Documentation Rule):**
> 1. **الالتزام الكامل بهندسة الأقسام المعزولة (`Modular Plug-and-Play — Zero-Overhead Isolation`)**: شرط أساسي غير قابل للتفاوض عند إنشاء أو تعديل أو إضافة أو حذف أي قسم في النظام الآن وفيما بعد؛ يجب أن يعمل كل قسم كوحدة مستقلة مسجلة في `DEFAULT_MODULES` (`app/db.py`) وفي `API_MODULE_MAP` (`app/modules_map.py`) ومحروسة بـ `erp_hooks.is_module_active` بحيث لا يسبب تعطيل أي قسم أي حمل أو استعلامات SQL أو أخطاء في بقية الأقسام.
> 2. **التوثيق الفوري الإلزامي**: أي تعديل أو إضافة أو حذف في المشروع يجب توثيقه فوراً في `AGENTS.md` و`CLAUDE.md` و`README.md` وكافة ملفات `docs/*.md` في نفس الطلب.
