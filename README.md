# تك زون للإلكترونيات (TechZone POS)

نظام نقاط بيع وإدارة محل عربي يعمل **offline بالكامل** داخل نافذة سطح مكتب واحدة، ومهيأ للسوق المصري (`ج.م`).

## أبرز المميزات

- **نقاط بيع ذكية (`pos.html`)**:
  - عند إدخال مبلغ نقدي **أكبر** من إجمالي الفاتورة يظهر **الباقي للعميل (الفكة)** تلقائياً ويُسجَّل في الفاتورة.
  - عند إدخال مبلغ نقدي **أقل** من إجمالي الفاتورة يظهر تحذير ويسأل الكاشير هل يود تحويل المبلغ المتبقي إلى **بيع آجل (مديونية)**، وعند الموافقة يتحول المتبقي تلقائياً إلى الآجل مع **إجبار الكاشير على اختيار أو تسجيل العميل**.
  - عند اختيار الدفع عبر **محفظة إلكترونية** (فودافون كاش / إنستا باي / إلخ) يظهر حقل إلزامي لكتابة **رقم العملية المرجعية** المرسل في الرسالة النصية ليظهر للمدير وفي الإيصال.
- **حسابات العملاء الآجلة وكشف الحساب وسندات القبض (`customers.html`, `customer_details.html`)**:
  - متابعة إجمالي المشتريات، إجمالي الآجل المسجل، إجمالي المسدد، والمديونية المتبقية لكل عميل مع فلتر «عليه مديونية فقط».
  - كشف حساب تفصيلي بالرصيد التراكمي وإمكانية **إصدار سندات قبض (`RCV-...`)** لتسديد الدفعات الآجلة نقداً أو بمحفظة إلكترونية.
- **نظام صلاحيات مخصص لكل موظف (`reports.html`)**:
  - حرية كاملة للمدير في منح أو سحب 15 صلاحية دقيقة لكل موظف على حدة في كل أجزاء المشروع (البيع، تعديل الأسعار، الاسترجاع، رؤية مبيعات الجميع، عرض المخزون، تعديل المخزون، رؤية التكلفة، عرض/تعديل/حذف العملاء وسندات القبض، الصيانة وقطع الغيار، شراء المستعمل، التقارير، والإعدادات).
- **تشغيل أو إيقاف الضريبة وإعدادات مصر (`receipt.html`)**:
  - إمكانية تشغيل أو إيقاف ضريبة القيمة المضافة بالكامل بضغطة زر للمحلات التي تعمل بدون ضريبة، مع ضبط العملة الافتراضية بالجنيه المصري (`ج.م`) ونسبة الضريبة الافتراضية `14%`.

## التشغيل والفحص

```powershell
python app\main.py
python app\selfcheck.py
```

- لبناء ملف تنفيذي `dist\TechZone.exe`: اضغط مرتين على `build-exe.bat`.
- لرفع المشروع والتعديلات إلى GitHub: اضغط مرتين على `push-github.bat`.
